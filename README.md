# Daffa Fairuzya — Portfolio

Static portfolio with 12 projects, a draggable gallery, video previews, project pages, About and contact.

HTML, CSS and JavaScript files are at the repository root, with local images and MP4 excerpts. No build or external dependencies required.

## Publish

GitHub repository Settings → Pages → Deploy from a branch → main → / (root).

## Edit

- Gallery data: js-gallery-data.js
- Styles: css-loum.css
- Gallery interaction: js-gallery.js
- Navigation, clock and original players: js-loum.js
- Pages: individual HTML files

Original Google Drive links require appropriate permissions. Local video excerpts are silent; use Watch original for complete films. Contact links open an email draft.
